GP26 and GP27 are electrically free today but earmarked by plan, not yet touched in firmware — nothing claims them until code is written.

The PX-42F is a custom RP2350A board (boards/px42f.h), not a Pico 2 W: there is no CYW43 radio, so GP23–25 and GP29 are free. I²C1 on GP26/27 remains the planned I²C bus.

The external reset button lands on RUN, not a GPIO — a dedicated hardware reset input firmware can't observe or block.
